# Аудит готовности репозитория

## Цель

Документ проверяет, достаточно ли репозиторий безопасен и понятен для публикации как портфолио-проект.

## Текущий статус

Статус: проект готов к публикации в отдельном GitHub-репозитории после переноса папки в самостоятельный репозиторий.

Сейчас проект виден как новая папка внутри родительского workspace, поэтому `git status --short` показывает:

```text
?? ./
```

Это нормально до инициализации проекта как отдельного Git-репозитория.

## Проверки безопасности

| Проверка | Результат | Подтверждение |
|---|---|---|
| `.env` исключен | Пройдено | `.gitignore` содержит `.env` и `.env.*`, но оставляет `.env.example` |
| сгенерированные отчеты исключены | Пройдено | `.gitignore` содержит `reports/*` и оставляет `reports/.gitkeep` |
| приватные датасеты исключены | Пройдено | `.gitignore` содержит `data/raw/` и `data/private/` |
| выгрузки таблиц и БД исключены | Пройдено | `.gitignore` исключает `*.xlsx`, `*.xls`, `*.sqlite`, `*.db` |
| архивы исключены | Пройдено | `.gitignore` исключает `*.zip`, `*.7z`, `*.rar` |
| Python-кеш исключен | Пройдено | `.gitignore` исключает `__pycache__/`, `*.py[cod]`, `.pytest_cache/` |
| локальное виртуальное окружение исключено | Пройдено | `.gitignore` исключает `.venv/` |
| CI workflow есть | Пройдено | `.github/workflows/ci.yml` запускает `.\scripts\preflight.ps1` |

## Чеклист публикации

Перед публикацией:

1. Создать отдельный репозиторий для проекта.
2. Запустить `.\scripts\preflight.ps1`.
3. Проверить `git status --short`.
4. Убедиться, что в статусе нет секретов и реальных клиентских данных.
5. Закоммитить исходный код, документацию, sample-данные и n8n-шаблоны.
6. Не коммитить `reports/`, кроме выбранных скриншотов или демо-артефактов.
7. Оставить `docs/assets/ads_dashboard.png`, если нужен визуальный пример в README.

## Файлы, которые можно коммитить

- `README.md`
- `pyproject.toml`
- `.env.example`
- `.gitignore`
- `src/`
- `tests/`
- `docs/`
- `data/sample/`
- `data/scenarios/`
- `integrations/n8n/`
- `projects/`
- `scripts/`

## Файлы, которые нельзя коммитить

- `.env`
- `.env.local`
- `service-account.json`
- реальные выгрузки WB/Ozon;
- приватные выгрузки Google Sheets;
- сгенерированные файлы баз данных;
- веса моделей;
- крупные сгенерированные артефакты.

## Оставшийся визуальный polish

Скриншот дашборда лежит в `docs/assets/ads_dashboard.png`. Дополнительные скриншоты плана действий или управленческой сводки могут усилить README, но для публикации они не обязательны.
