# План укрепления проекта

Цель: довести проект от MVP до состояния серьезного продуктового кейса автоматизации.

## Что сейчас не делать

- Не расширять WB/Ozon/n8n-интеграции без отдельного запроса.
- Не делать вид, что подключены production-доступы маркетплейсов.
- Не добавлять новые функции без улучшения качества решений, тестов и отчетности.

## Критерии солидного проекта

- Бизнес-решения объяснимы.
- Отчеты не только описательные, а пригодны для действий.
- Edge cases покрыты тестами.
- Ограничения явно описаны.
- Репозиторий можно публиковать без generated noise и секретов.
- Читатель понимает систему за 10 минут.
