# 7-дневный план выполнения

Цель недели: довести портфолио до состояния, которое можно показывать как прикладной кейс автоматизации для маркетплейсов.

## День 1

- Сделать MVP трех кейсов.
- Добавить sample-data.
- Добавить README и команды запуска.
- Проверить unit-тестами.

## День 2

- Поднять FastAPI слой.
- Добавить скриншоты HTML-отчета.
- Подготовить GitHub README с картинками и коротким demo flow.

## День 3

- Импортировать n8n workflows.
- Подключить тестовую Google Sheet.
- Сделать Telegram digest на тестовый чат.

## День 4

- Улучшить рекламный блок: недельная динамика, аномалии, сравнение WB/Ozon.
- Добавить экспорт рекомендаций по ставкам.

## День 5

- Улучшить review-agent: tone of voice, категории SKU, ручной approve перед отправкой.
- Добавить безопасный LLM provider как optional слой.

## День 6

- Улучшить competitor monitor: парсер/ручной импорт CSV, Notion backlog, content brief.
- Добавить unit-экономику SKU: комиссия, логистика, маржа, точка безубыточного ДРР.

## День 7

- Финальная чистка README.
- Записать короткое demo-видео или сделать скриншоты.
- Опубликовать GitHub.
- Опубликовать репозиторий и проверить публичные ссылки.
