# Краткое описание демо

Проект показывает автоматизацию ежедневного операционного контура маркетплейс-команды.

## Что делает система

1. Читает таблицы рекламы, отзывов, конкурентов, keyword plan и unit economics.
2. Валидирует обязательные поля и качество данных.
3. Считает рекламные метрики, ДРР, ROAS, прибыль после рекламы и break-even thresholds.
4. Классифицирует отзывы, готовит безопасные drafts и обращения в поддержку.
5. Находит конкурентные разрывы по цене, рейтингу, отзывам и рекламному давлению.
6. Собирает общий action plan, Telegram digest и Notion task payloads.

## Что открыть в первую очередь

- `README.md` — общий обзор проекта.
- `docs/case_study.md` — описание задачи, решения и ограничений.
- `docs/architecture.md` — архитектура и границы интеграций.
- `reports/action_plan.md` — главный операционный результат.
- `reports/ads_dashboard.html` — визуальный отчет по рекламе.

## Короткая формулировка

```text
Это воспроизводимый контур автоматизации marketplace operations:
Python отвечает за бизнес-логику и проверки, n8n/Sheets/Telegram/Notion
используются как интеграционный слой, а итогом работы становится
приоритетный action plan для рекламы, отзывов и SEO/content задач.
```

## Что не заявлять

- Реальные production API маркетплейсов не подключены.
- Sample-данные не являются клиентскими или коммерческими данными.
- Ответы на отзывы не публикуются автоматически.
- Production rollout требует credentials, retries, rate limits, мониторинга и проверки порогов на реальных данных.
