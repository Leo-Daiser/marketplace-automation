# 02 Агент обработки отзывов

## Задача

Сократить ручную обработку отзывов: классифицировать отзывы, подготовить безопасные черновики ответов и сформировать обращения в поддержку.

## Что делает

- определяет тональность;
- определяет тему: доставка, вкус, эффект, упаковка, цена, индивидуальная реакция;
- назначает срочность;
- генерирует черновик ответа;
- создает обращения в поддержку для проблемных отзывов;
- готовит Telegram-дайджест.

## Вход

`data/sample/reviews.csv`

## Выход

- `reports/review_replies.csv`
- `reports/support_tickets.csv`
- `reports/review_digest.md`

## Запуск

```powershell
$env:PYTHONPATH = ".\src"
python -m marketplace_automation.cli review-agent --input .\data\sample\reviews.csv --out-dir .\reports
```

## Критерии готовности

- негативные отзывы не теряются;
- потенциально медицинские случаи поднимаются в высокий приоритет;
- ответы не содержат медицинских обещаний;
- workflow можно перенести в n8n.
